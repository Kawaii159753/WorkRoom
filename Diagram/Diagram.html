03
Secrets Vault & Security Architecture (backend/secrets/)
การจัดเก็บคีย์ลับแยกเป็นสัดส่วน พร้อมระบบ Auto-Discovery และ Template
1. Database Secrets (database.env)
DATABASE_URL
Port 6543 (Transaction Pooler with pgbouncer=true)
DIRECT_URL
Port 5432 (Session Mode for Prisma Migrations)
SUPABASE_ANON_KEY
Client Public Publishable Key
Template: database.example.env
ไฟล์แม่แบบสำหรับคัดลอกตั้งค่า (Tracked in Git)
2. Auth Security (auth.env)
JWT_SECRET
HS256 Token Signing Secret (32+ chars)
COOKIE_SECRET
HttpOnly Session Cookie Signing Key
JWT_EXPIRES_IN="7d"
Token Lifetime Window
Template: auth.example.env
ไฟล์แม่แบบสำหรับคัดลอกตั้งค่า (Tracked in Git)
3. Server Config (app.env)
PORT=4000
Express Backend Listening Port
CLIENT_URL="http://localhost:3000"
CORS Origin Allowed Domain
NODE_ENV="development"
Runtime Profile (development / production)
Template: app.example.env
ไฟล์แม่แบบสำหรับคัดลอกตั้งค่า (Tracked in Git)
🛡️ Auto-Discovery Order: src/config/env.ts จะค้นหาและโหลด Secrets ตามลำดับ: WORKROOM_SECRETS_DIR → backend/secrets/ → secrets/ → .env (Fallback)
🔐 Strict Git Ignore: ไฟล์ *.env ที่มีข้อมูลรหัสจริงถูกบล็อกไม่ให้ commit ขึ้น Git 100% (อนุญาตเฉพาะ *.example.env)

05
Real-time Collaboration & Concurrency Engine
ระบบการทำงานประสานกันแบบสดผ่าน Socket.IO ควบคู่กับ Optimistic Concurrency Control (OCC)
1. Room Channels & Presence
Workspace & Room Channels
workspace:join / workspace:leave
room:join / room:leave
Live Presence Events
presence:room_user_joined
presence:room_user_left
Scope-Isolated Broadcasting
ส่งข้อมูลเฉพาะสมาชิกที่อยู่ในห้องเดียวกันเท่านั้น เพื่อประหยัด Bandwidth
2. Live Multi-User Cursors
30 FPS Motion Stream
ส่งพิกัดเมาส์ผ่าน cursor:move ด้วย requestAnimationFrame throttling
Real-time Cursor Render
รับผ่าน cursor:updated พร้อมแสดงป้ายชื่อและสีประจำตัวผู้ใช้
LERP Position Smoothing
คำนวณการเคลื่อนไหวของเมาส์เสมือนให้นุ่มนวลเป็นธรรมชาติ
3. Optimistic Concurrency (OCC)
Room-Scoped State API
GET /api/v1/rooms/:id/state
PUT /api/v1/rooms/:id/state
Version Counter & Atomic Increment
ตรวจสอบ version ในตาราง RoomState ก่อนบันทึกทุกครั้ง
409 Conflict Protection
ปฏิเสธเมื่อ version ไม่ตรงกัน ป้องกันปัญหา Lost Update จากการเซฟทับกัน
🚀 High Performance: ลดปริมาณ Network Payload โดยแยกการบันทึก State เป็นระดับห้องย่อย และกระจาย Cursor ผ่าน WebSocket แบบ Throttled
